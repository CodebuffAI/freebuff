Sebelum membuka ke publik

opencode serve / opencode web memberi kendali penuh atas sesi agen dan filesystem. Jangan menaruhnya langsung di internet. Minimal: 

OPENCODE_SERVER_PASSWORD='ganti-ini' \
  opencode web --port 4096 --hostname 127.0.0.1

Lalu taruh reverse proxy (Caddy/Nginx) dengan HTTPS dan basic-auth di depannya. Repo nexusrootlab/incident mendokumentasikan kebocoran data lintas-sesi pada OpenCode Zen — alasan tambahan untuk tidak mengekspos instance tanpa autentikasi.

Menjalankan permanen

Dua proses, dua port. Contoh systemd di mesin/VPS Anda sendiri:

[Unit]
Description=opencode headless server
After=network.target

[Service]
Environment=OPENCODE_SERVER_PASSWORD=RAHASIA
ExecStart=/usr/local/bin/opencode serve --port 4096 --hostname 127.0.0.1
Restart=always

[Install]
WantedBy=multi-user.target

Untuk hub dan server data (dari folder ini):

node data-server.mjs &
node hub-server.mjs

Halaman ini bukan produk resmi opencode maupun Freebuff, dan tidak berafiliasi dengan tim opencode.
